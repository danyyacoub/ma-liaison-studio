# Ma Liaison Studio

A small iPhone web app for Ma Liaison: add a black price sticker to outlet photos and videos, drag it into place, and save the result for Instagram and TikTok stories or a TikTok photo slideshow.

Everything runs on the phone. Photos and videos are never uploaded.

## Install on iPhone

1. Open https://danyyacoub.github.io/ma-liaison-studio/ in Safari.
2. Tap Share, then **Add to Home Screen**.

## Updating

The app is a single `index.html`. After changing it, bump `VERSION` in `sw.js` so installed copies pick up the new version.
